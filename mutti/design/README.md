# Mutti identity

Shared foundation with kurtz: Graphite `#1F1F1F`, Ivory `#FAF8F1`, Electric Yellow
`#FFE600`, Sora (SIL OFL). Mutti has its own rounded twin-arch m and wordmark.
Tokens are in `tokens.json`; source vectors and font licenses are in `assets/`.
Yellow buttons carry graphite text. Light-theme links use the darker accessible
accent `#625800`; yellow is decorative on ivory. Existing third-party notices stay.
The Mac native title bar uses system controls; the shared web UI loads Sora locally.
