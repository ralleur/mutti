Kurt — Hauser / Ralleur

Existing owner-provided artwork from the private Hauser Kurt lab, version 11,
reused in the local Mutti import preview at the owner's request, 2026-10-05.
Includes AI-generated drawings developed for Hauser; not stock artwork.
No new public artwork license is granted or inferred here.

Only the requested action frames and their effects are included. Drawings are
unchanged; frames are deduplicated and repacked into lossless WebP atlases.
Source filenames and SHA-256 hashes: provenance.json.
Reproduce with Node and the existing Hauser Sharp dependency:
  node mutti/packaging/export-kurt.mjs /path/to/smart-home-hmi

The new Mutti exporter and animation player have their own GPL-2.0-or-later
source notices. No Hauser application/runtime source is bundled.
