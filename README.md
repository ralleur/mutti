# Mutti

**Deine Medien. Gut zu Hause.**

Mutti ist das Server-Gegenstück zu [kurtz](https://github.com/ralleur/kurtz),
auf Basis von [Jellyfin](https://github.com/jellyfin/jellyfin) v12.1.
Mac-App und Docker/NAS verwenden denselben Server und dieselbe
[Mutti-Weboberfläche](https://github.com/ralleur/mutti-web).

**Entwicklungsvorschau, kein fertiges Day-1-Release.** Lokale Einrichtung,
Marke, Mac-Prozesssteuerung und Container-Paketierung stehen zur Prüfung bereit.
Sichere QR-Gerätekopplung und direkter Fernzugriff sind noch nicht implementiert.
Es gibt keinen eingebauten Relay und keine externe Kontopflicht.
